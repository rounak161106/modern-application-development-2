In applications, we have a lot of components inside a parent component, there may be component inside components and in this case, sharing of information across these components become difficult if we use the conventional props and emit way. In order to solve this, we have a data store which stores all the data and any component could access this. this is called as state management and when we change the state(data) from any component, it is changed universally and whatever components who are dependent on that data store will be changed/modified due to the change made by any one of the component. We could also keep track of the component who changed the data.
